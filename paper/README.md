# Paper: "When Vision Goes Dark"

CVPR-style paper generated **entirely from experiment artifacts**. Every table
in `results/` and every macro in `results/numbers.tex` is auto-generated by
`make_paper_tables.py` from the committed CSVs in `../results_pilot/` — never
edit them by hand.

## Build (any TeX Live 2023+ / Overleaf)

```bash
make            # pdflatex + bibtex + 2x pdflatex
make clean
```

Or on Overleaf: upload this folder as a project (keep the directory layout),
set the compiler to pdfLaTeX, main document `main.tex`. Overleaf note: when
upgrading from pilot to full-scale results, re-upload `results/` and
`figures/`.

## Layout

```
main.tex                 the paper (anonymous, review mode)
references.bib           bibliography (all keys verified against main.tex)
cvpr.sty                 official CVPR style (vendored from cvpr-org/author-kit)
ieeenat_fullname.bst     official bibliography style (vendored)
results/*.tex            AUTO-GENERATED tables + macros (from ../results_pilot/)
figures/*.pdf|png        AUTO-GENERATED publication figures (make_paper_figures.py)
CVPR2027_CHECKLIST.md    submission-readiness audit
supl.tex                 supplementary material stub
```

## Regenerating results → paper

```bash
python3 make_paper_tables.py  --results ../results_pilot --out results
python3 make_paper_figures.py --results ../results_pilot --out figures
make
```

For the full-scale GPU run, point `--results` at the downloaded Colab
`results/` directory; the same commands rebuild every table and figure.
